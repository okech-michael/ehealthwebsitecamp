This folder contains public assets for the Ehealth website.

Add the following files here before production deployment:
- favicon.ico (32x32 or 64x64)
- favicon-16x16.png
- favicon-32x32.png
- apple-touch-icon.png (180x180)
- og-image.jpg (1200x630) — for Open Graph social sharing
- logo.svg — vector Ehealth logo
- logo-dark.svg — dark mode variant
